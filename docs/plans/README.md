# Plans

Part of [the documentation index](../README.md). A plan holds intent and steps for
work that is not finished. Each plan states its status under its title: **active**
while the work runs, **done** when it has shipped, and a done plan is deleted
(git keeps it) once its current facts live in product, architecture or operations pages.
