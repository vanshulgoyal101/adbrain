# Release: generation routing and Meta reliability

Date: 2026-09-06

## Scope

This release combines the creative-generation overhaul already deployed with
low-risk LLM routing and the local Meta/campaign reliability changes released
from the workspace.

## Creative generation

- A structured creative concept now owns copy, visual medium, art direction,
  source-grounded claims, placement and text position before image generation.
- Invalid model output receives one concrete repair attempt. Repeatedly invalid
  output is rejected before image spend.
- Image execution discovers OpenRouter endpoint capabilities rather than sending
  unsupported model options. References, aspect ratio, quality and resolution
  are selected from the endpoint contract.
- Image bytes are decoded and validated as a single bounded raster. The Linux
  Sharp runtime is explicitly included in Vercel tracing.
- Paid creative generation uses OpenRouter text and image providers. Explicit
  fallback is disabled in Production; a fallback, if configured elsewhere, is
  recorded in the generation receipt.
- Batch generation saves successful variants independently and exposes sibling
  failures. Failed storage or composition cannot become a finished creative.
- Each creative stores its concept, image prompt, model/provider receipt,
  placement, references and image dimensions in `creatives.generation`.
- Studio exposes the receipt and supports portrait, square, story and landscape
  placements.

## Task-aware LLM routing

Not every task deserves the expensive creative model. The orchestrator now has
explicit routing pools:

- `standard`: `LLM_PROVIDER_ORDER`; used for creative planning and campaign
  planning because those tasks affect creative quality, budget or destination.
- `budget`: `LLM_BUDGET_PROVIDER_ORDER`; defaults to `groq,google,cerebras` and
  excludes OpenRouter. Used for website brand extraction, the creative brief
  interview and campaign performance summaries.

Production has:

```text
LLM_BUDGET_PROVIDER_ORDER=groq,google,cerebras
```

Budget tasks fail closed if the budget pool has no keys. They do not silently
fall through to the paid OpenRouter pool. Provider errors identify the task
that failed instead of giving creative-specific troubleshooting advice.

## Meta and campaign reliability

The local Meta/campaign slice included in this release:

- Maps human creative CTA labels to a safe Graph API lead-ad CTA. A presentation
  CTA such as `Book Now` is no longer sent blindly where Meta expects a different
  lead-form CTA.
- Validates the selected lead form against the current Meta account before
  creating a campaign, preventing stale-form failures.
- Preserves explicit WhatsApp/call destinations and returns actionable errors
  when the connected Page cannot support them. It no longer silently changes the
  requested destination to an instant form.
- Validates creative image URLs before upload and hides raw localized/provider
  errors behind stable customer-facing guidance for CTA, permissions, targeting,
  budget and creative failures.
- Prevents duplicate assistant requests with an in-flight lock and reports
  non-JSON/server failures with HTTP status context.
- Teaches the interview planner that `Let the AI decide` and `Surprise me` are
  completed answers rather than unanswered fields.

## Database and deployment

The `creatives.generation` JSONB migration was applied to the AdBrain Supabase
project and verified through PostgreSQL metadata and PostgREST before this
release. Existing creative rows were unchanged.

Production environment includes the paid creative settings and the budget pool:

```text
LLM_PROVIDER_ORDER=<premium creative/campaign pool>
LLM_BUDGET_PROVIDER_ORDER=groq,google,cerebras
OPENROUTER_MODEL=qwen/qwen3.8-max-0902
OPENROUTER_IMAGE_MODEL=openai/gpt-image-2
IMAGE_PROVIDER=openrouter
IMAGE_PROVIDER_FALLBACK=none
```

Secret values are intentionally omitted from this document.

## Known limits

- Budget providers may still be billable depending on their account plan; the
  routing policy means "non-OpenRouter/low-cost pool," not a billing guarantee.
- Quota checks are not atomic reservations across concurrent requests.
- Meta permissions, Page capabilities and lead-form availability remain external
  provider conditions and must be verified in the connected account.
- No automatic visual judge or performance guarantee exists for generated ads.
- Existing unrelated workspace edits are included in this release only when they
  are part of the staged release diff; no secrets are committed.
