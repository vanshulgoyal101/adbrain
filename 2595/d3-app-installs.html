Notes for the phase-3 UI (after the evidence gate; owners per CTO's slices)

  1. 1Brand "Your app" card after Website. Two optional fields (Google Play, App Store), saved with no Meta or WhatsApp needed. Its own brand-app-card.tsx; brand-form.tsx is already too long.
  2. 2Pick the Meta app only when connected: one radio row per RegisteredApp, with a ✓/! line per OS saying whether that app lists the Brand link. Never pre-pick when there are two. Check again plus "Meta app settings ↗" (44 px) and the checked time.
  3. 3unsafe_link is a field error at save time: HTTPS, exactly play.google.com / apps.apple.com, no short links, no username or password. Same rule as normalizeStoreUrl.
  4. 4Phone type is a 2-column radio group. An OS with no Brand link stays visible as aria-disabled with "Not in Brand". The hint says another phone type needs its own reviewed campaign. No automatic second ad set or budget.
  5. 5Show the full store link as host/path, with "Open ↗" and "Change in Brand", like website ads (#2600).
  6. 6The preview shows the actual validated button (Install now), taken from the ad, never fixed copy.
  7. 7Results counted within shows the campaign's attribution setting as Meta returns it, never fixed copy. Directly under it: "Install counting: not confirmed". Never infer SDK/MMP readiness from a listing or past installs.
  8. 8Blocker copy for the eight AppBlocker values (wording in the HI/EN table): unreadable, no_app → Check again + Meta app settings; no_store_link, unsafe_link → Change in Brand; app_not_available, ambiguous → Choose app (Brand); os_mismatch, link_not_registered → Meta app settings ↗ + Check again. Send stays off.
  9. 9Install counting is information, never a blocker (CTO, 6604535267): nothing AdBrain can read proves the SDK/MMP is set up, so a blocker could never clear. The same grey line stays on a blocked Review. If Meta later exposes a readable install signal, it becomes a blocker then.
  10. 10A change to the app, phone type, link or budget after Review invalidates the reviewed hash. Show this as information with one "Review again" button, not as an error.
  11. 11Manage shows installs and cost per install for the same date range, from Meta insights, with the attribution line. It never says customers or enquiries.
  12. 12Measured zero is "0" and "—". Unavailable (Meta returned no install metric) is a grey info box with no numbers. A late sync is amber, with the last sync time and Sync now. These three never share copy.
  13. ✓Rendered EN 390 and HI 360: no overflow, every target ≥ 44 px, buttons on one line. HI is a draft for the CPO's words check.
